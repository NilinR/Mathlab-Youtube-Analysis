# Mathlab-Youtube-Analysis
Analyzed YouTube viewership data using MATLAB and Python, developing models to predict trends and identify engagement. Applied the Matrix Inversion Method to compute coefficients and compared model accuracy for future predictions.

•	The primary objective is to create mathematical models capable of predicting observed patterns in viewership to the maximum possible accuracy. 

•	The Matrix Inversion Method is employed to fit both a second-degree polynomial/parabola (y = ax² + bx + c) and a linear curve (y = ax + b) to the collected dataset, which has month numbers (x) and monthly increment in views (y). 

•	Furthermore, the analysis also identifies peaks and lows within specific time intervals, offering insights into viewership fluctuations of the channel. 

•	The ultimate goal is to derive meaningful conclusions about the viewership behavior of the YouTube channel and recommend which mathematical model, either the second-degree polynomial or linear curve, is better for predicting future viewership trends.

For this analysis, data will be collected exclusively from Social Blade, a comprehensive analytics platform for YouTube channels, including the Marvel YouTube channel. Social Blade provides detailed historical data, including monthly view counts, subscriber counts, and other relevant metrics.

MATLAB provides a versatile environment for numerical computing and data visualization, making it well-suited for the complexities of matrix operations involved in the Matrix Inversion Method.
